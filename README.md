# Registro de Empleados

## Descripción

Programa realizado en Python para llevar un registro de empleados. Permite ingresar al sistema y utilizar diferentes opciones para manejar la información guardada en una base de datos SQLite.

## Tecnologías utilizadas

- Python
- SQLite
- Visual Studio Code
- GitHub

## Requisitos

- Tener Python instalado.
- Contar con los archivos del proyecto.
- Tener un editor para ejecutar el programa.

## Instalación

1. Descargar los archivos del proyecto.
2. Guardarlos dentro de una misma carpeta.
3. Abrir la carpeta en Visual Studio Code.

## ¿Cómo ejecutar el proyecto?

Abrir la terminal dentro de Visual Studio Code y ejecutar:

`python main.py`

Al iniciar, aparecerá el acceso al sistema y luego el menú con las opciones disponibles.

## Operaciones disponibles

- Registrar empleado.
- Mostrar empleados.
- Buscar empleado.
- Actualizar información.
- Eliminar empleado.
- Cerrar sesión.
- Salir del sistema.
